# Fonts for Aarogya Ruchi Mobile App

This directory should contain the following font files:

## Display Fonts (Bricolage Grotesque)
- `BricolageGrotesque-Bold.ttf`
- `BricolageGrotesque-SemiBold.ttf`
- `BricolageGrotesque-Regular.ttf`

Download from: https://github.com/fonthausen/Bricolage-Grotesque

## Body Fonts (Inter)
- `Inter-Regular.ttf`
- `Inter-Medium.ttf`
- `Inter-SemiBold.ttf`
- `Inter-Bold.ttf`

Download from: https://github.com/rsms/inter/releases

## Accent Font (Londrina Solid)
- `LondrinaSolid-Regular.ttf`

Download from: https://fonts.google.com/specimen/Londrina+Solid

## Quick Setup

1. Download the fonts from the links above
2. Place the TTF files in this directory
3. Restart the development server

Note: The app will use system fonts as fallback until these fonts are added.
