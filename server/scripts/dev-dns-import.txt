; Cloudflare DNS import file — aarogyaruchi.com zone, DEV environment.
;
; How to apply (one time): Cloudflare dashboard → aarogyaruchi.com zone →
; DNS → Records → Import and open this file. Re-importing is safe (existing
; records are skipped/updated). All three hostnames point at the dedicated
; dev tunnel whose connector container runs on the dev box (server/deploy-dev.sh).
;
; BEFORE IMPORTING: replace every <dev-tunnel-id> below with the dev tunnel's
; UUID. It is deliberately not committed (this repo is public) — it lives in
; server/.dev-tunnel-id or ~/.cloudflared/<uuid>.json on the operator machine.
;
;   dev-api    → Go API          (public by design; OTP/session auth)
;   dev-db     → Adminer         (basic auth, user lohit — same password
;   dev-cache  → redis-commander  as the prod db/cache UIs; Caddyfile.dev)
;
; NOTE: dev-grafana (self-hosted monitoring) deliberately lives on the
; lohitcode.com zone instead — dev-grafana.lohitcode.com, same tunnel,
; DNS created via `cloudflared tunnel route dns` (cert.pem manages that
; zone locally; this file only covers aarogyaruchi.com).
;
; Records MUST be proxied (orange cloud) — the tunnel only receives
; Cloudflare-edge traffic. Cloudflare imports CNAMEs as proxied by
; default; verify the orange cloud on all three after importing.
;
; NOTE: dev.aarogyaruchi.com (the dev website) is NOT here on purpose —
; it is a worker custom domain managed automatically by wrangler
; (`bun run deploy:dev`); a manual record would conflict with it.
;
; Cleanup suggestion while you're in there: the stray
; dev-api.aarogyaruchi.com.lohitcode.com record in the lohitcode.com zone
; (created by accident) can be deleted.
